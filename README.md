# Fekka — فكّة

Personal finance tracker built for Egypt.

## Run it
```
npm install
npx expo install --fix
npx expo start
```
Scan the QR code with **Expo Go** on your phone.

## Tabs
- **Home** — net worth, what's left this month, upcoming payments
- **Spend** — one-tap daily expenses by category, income
- **Pay** — installment apps (valU, Souhoola, Klivvr, Sympl, Contact, Aman, Forsa, Halan…) and loans (mortgage, car, personal, credit card)
- **Save** — gold 21K/24K, USD, EUR, EGP cash with editable rates

Long-press any item to delete. Data is stored on-device.
